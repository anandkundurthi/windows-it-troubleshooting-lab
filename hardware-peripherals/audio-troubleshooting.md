# Audio and Peripheral Troubleshooting

## Scope
Basic first-line checks for microphone, speaker, headset, keyboard, mouse and external display symptoms.

## First-line checks
1. Ask which device is affected and whether it ever worked on this computer.
2. Check physical connection, power, mute switch and volume level.
3. For audio, review **Settings > System > Sound** and confirm the expected input/output device is selected.
4. For USB peripherals, try an approved alternate port if safe and permitted.
5. Review Device Manager for the relevant device status; record exact messages.
6. Check whether the peripheral works on another authorized device, if available.

## Caution
Do not install third-party driver utilities or change drivers without approval. Avoid disconnecting devices that support critical operations.
