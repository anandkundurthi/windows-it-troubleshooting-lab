# Printer Troubleshooting

## Intake questions
- Is the printer local (USB) or network-connected?
- Is it powered on and showing an error light/message?
- Can other users print to it?
- Is the issue limited to one document or all print jobs?
- Is there paper, toner/ink, or a paper jam indication?

## First-line checks
1. Confirm power, display status, paper and consumables.
2. Check the cable or approved network connection.
3. Confirm the user selected the correct printer and queue.
4. Check whether the printer is paused or offline in Windows printer settings.
5. Ask whether other users are affected.
6. Record any error message and whether a test page is permitted.

## Caution
Do not clear shared print queues, remove drivers, change printer IP settings or restart shared print servers without authorization. A shared printer issue may affect many users; assess impact before action.
