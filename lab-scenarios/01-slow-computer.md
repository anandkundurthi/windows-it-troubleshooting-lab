# Lab Scenario 01: Slow Computer

**Type:** Practice scenario. This is not a record of a real incident.

## Scenario
A fictional employee reports: "My Windows computer has become slow, and applications take longer than usual to open."

## Objectives
- Gather symptoms and scope.
- Use Task Manager to observe CPU, Memory and Disk.
- Check available storage.
- Record evidence without assuming the cause.
- Verify an approved action or escalate.

## Suggested workflow
1. Ask when the problem began and whether one or several applications are affected.
2. Open Task Manager and observe resource usage over time.
3. Identify any sustained resource use and note the process name.
4. Check Settings > System > Storage.
5. Decide whether a safe action is appropriate or escalation is required.
