# Lab Scenario 07: Incident Documentation

**Type:** Documentation exercise using one of the other scenarios.

## Task
Choose one completed practice scenario and create a copy of `../incident-reports/incident-report-template.md` (or paste its structure into a new report). Use a fictional reporter and avoid real personal or network data.

## Review checklist
- [ ] User's issue is summarized clearly.
- [ ] Category, impact, urgency and priority are recorded using the practice policy.
- [ ] Diagnostic steps and observations are separated.
- [ ] Suspected cause is not presented as confirmed fact.
- [ ] User updates are clear and professional.
- [ ] Resolution is verified or escalation is justified.
- [ ] No passwords, tokens or confidential identifiers are included.
