# Lab Scenario 02: Application Error

**Type:** Practice scenario. Use a harmless, non-critical application on your own device; do not intentionally damage software.

## Scenario
A fictional employee reports that an application displays an error when opened.

## Objectives
- Collect the application name, version if available and exact error.
- Determine whether the issue affects one application or several.
- Reproduce the issue safely.
- Review relevant Event Viewer information only if appropriate.
- Document a safe next step and escalation decision.
