# Lab Scenario 04: Name Resolution

**Type:** Practice scenario using a public test domain or a hostname you are authorized to test.

## Scenario
A fictional employee can reach some network resources but reports that one hostname does not open.

## Objectives
- Confirm the exact hostname and scope.
- Run `nslookup` and record the response.
- Distinguish a DNS response from general network reachability.
- Avoid changing DNS settings without approval.
