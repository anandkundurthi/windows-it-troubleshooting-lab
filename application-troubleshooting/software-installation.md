# Software Installation Issues

## Intake questions
- What software is being installed and for what business purpose?
- Is it organization-approved?
- What is the source of the installer?
- What exact error appears and at what installation stage?
- Does the user have the required permissions or deployment method?

## First-line checks
1. Verify the software is approved by the organization.
2. Confirm the installer came from the official vendor or approved software portal.
3. Check system requirements and Windows compatibility.
4. Record the exact error code/message and time.
5. Check available disk space if relevant.
6. Determine whether installation is managed through company software deployment.
7. Escalate permission, licensing, package or endpoint-management issues to the appropriate team.

## Security rules
Never download software from untrusted mirrors, bypass administrator controls, disable antivirus, or run unknown installers. Do not ask users to share administrator passwords. Do not attempt to circumvent licensing or policy restrictions.
