# Application Errors and Crashes

## Intake questions
- Which application and version (if known) is affected?
- What exact action causes the error?
- What is the exact error message and when did it occur?
- Does it affect one user or multiple users?
- Did the issue begin after an update or configuration change?
- Is work saved and backed up?

## First-line workflow
1. Confirm the application name and whether other applications work.
2. Capture the exact error text; avoid screenshots containing confidential data.
3. Ask the user to save work if possible.
4. Close and reopen the application normally with user agreement.
5. Check whether the issue is reproducible and document the steps.
6. Review Event Viewer only if appropriate and authorized; correlate application errors with the time of failure.
7. Check approved vendor/service status or known issue communications.
8. Escalate recurring crashes, data-loss risk, security warnings or multi-user incidents.

## Caution
Do not delete application profiles, clear application data, edit the registry, disable security software or reinstall business-critical applications without approval and a backup/change plan.

## Verification
Ask the user to repeat the original task and confirm whether the error is gone.
