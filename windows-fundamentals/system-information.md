# Windows System Information

## Objective
Identify basic hardware and operating-system details before investigating a desktop issue.

## Tool
System Information (`msinfo32`).

## Procedure
1. Press `Win + R`.
2. Enter `msinfo32` and press Enter.
3. Select **System Summary**.
4. Locate OS Name, Version, System Manufacturer, System Model, Processor, Installed Physical Memory (RAM) and System Type.
5. Record only the details needed for the support case. Do not publish serial numbers, product IDs or other sensitive identifiers.

## Why a service desk analyst uses it
The information helps identify the Windows environment and hardware context. It can support compatibility checks and help an analyst decide what information to include in an escalation.
