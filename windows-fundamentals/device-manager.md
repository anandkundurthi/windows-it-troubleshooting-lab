# Device Manager

## Objective
Review Windows device status when hardware or peripheral problems are reported.

## Open Device Manager
1. Right-click Start.
2. Select **Device Manager**.
3. Expand the relevant category (for example, Network adapters, Display adapters, Sound, video and game controllers, or Printers).
4. Review the device name and status. A warning symbol may indicate a device or driver problem; inspect Properties and the Device status message.

## First-line checks
- Confirm the device is connected, powered on and enabled where appropriate.
- Ask whether the issue began after a device, Windows or driver update.
- Record the device name and exact status/error text.
- Check approved vendor or organizational guidance.

## Caution
Do not uninstall devices, delete drivers, use **Update driver** from an untrusted source, or change device settings without authorization. Driver changes can make a device unavailable and may require administrative privileges.
