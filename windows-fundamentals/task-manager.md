# Task Manager

## Objective
Inspect running applications and resource utilization when a user reports slow or unresponsive performance.

## Open Task Manager
- Press `Ctrl + Shift + Esc`, or right-click Start and select **Task Manager**.
- If the compact view appears, select **More details**.

## Useful areas
- **Processes:** running apps and background processes; review CPU, Memory, Disk and Network columns.
- **Performance:** live graphs for CPU, memory, disks, Wi-Fi/Ethernet and GPU.
- **Startup apps:** shows applications configured to start with Windows and their startup impact.
- **Users:** shows resource use by signed-in sessions where available.

## Safe first-line workflow
1. Ask when the slowdown began and whether it affects one app or the whole device.
2. Observe CPU, Memory and Disk utilization over a short period; a brief spike may be normal.
3. Identify the process with sustained high usage and note its exact name.
4. Ask whether the user recognizes the application and whether work is saved.
5. Close an unresponsive user application only with the user's agreement and after warning about unsaved work.
6. Do not end unfamiliar system, security or management processes.
7. Record observations and check whether performance improves.

## Do not
- Disable startup items without user/IT approval.
- End security, backup, encryption or management processes.
- Assume that high utilization alone proves the root cause.
