# High CPU Usage

## Objective
Investigate sustained high CPU utilization reported by a user.

## Procedure
1. Open Task Manager.
2. Select **Processes** and sort by CPU.
3. Observe the system for a short period and note whether usage remains high.
4. Identify the process name and whether it is a known user application, Windows component or managed security tool.
5. Ask the user what task was running and whether the behavior is expected.
6. If the process is an ordinary user application and the user agrees, save work and close it normally.
7. Recheck CPU usage and the original symptom.

## Cautions
Do not terminate unfamiliar processes or Windows/security/management services. Do not disable antivirus, endpoint detection, updates or monitoring agents. Escalate persistent high usage from system processes or unknown executables.
