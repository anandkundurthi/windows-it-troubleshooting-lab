# Slow Computer Troubleshooting

## Problem description
A user reports that Windows or applications respond slowly.

## Intake questions
- When did the slowdown begin?
- Is the whole computer slow, or only one application?
- Does it happen continuously or at particular times?
- Did anything change recently (updates, new software, peripherals)?
- Is there an error message? Capture its exact wording without sensitive data.

## Initial diagnostic steps
1. Confirm whether other users or devices are affected.
2. Open Task Manager (`Ctrl + Shift + Esc`).
3. Observe CPU, Memory and Disk utilization; note sustained patterns rather than one-off spikes.
4. Review the Processes tab for an identifiable application consuming resources.
5. Check available storage in **Settings > System > Storage**.
6. If appropriate, review recent errors in Event Viewer; focus on entries that match the reported time and application.
7. Record observations before making changes.

## Possible causes to investigate
- A resource-intensive application or workload
- Low available memory or storage
- A background update, scan or synchronization task
- An application fault
- A hardware, thermal or disk issue requiring specialist diagnosis

These are possibilities, not conclusions. Confirm with evidence.

## Safe resolution options
- Close an identified, non-essential user application after confirming work is saved and obtaining user agreement.
- Restart only with the user's agreement, after saving work and checking for active tasks.
- Use organization-approved storage cleanup guidance; do not delete user files.
- Escalate suspected hardware, thermal, malware or recurring system faults.

## Verification
Ask the user to repeat the task that was slow. Record whether response improved and whether the issue recurs.
